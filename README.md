# STM32 Smart Car Project
## 基于 STM32F103 & FreeRTOS 的智能避障循迹小车

项目名称： 基于 STM32 与 FreeRTOS 的多模态高性能自主移动机器人

项目概述： 设计并开发了一款基于 RTOS 架构的嵌入式智能小车，集成了PID 循迹、陀螺仪辅助避障、蓝牙遥控及数据可视化调试功能。针对低成本电机非线性极强的问题，设计了特殊的补偿算法，并引入 A/B 测试验证算法性能。

技术栈：

硬件： STM32F103、MPU6050 (6轴姿态)、8路红外灰度传感器、超声波测距、蓝牙透传。

软件： C语言、FreeRTOS、HAL库、PID控制算法、I2C/UART/PWM 通信。

核心亮点与贡献：

RTOS 系统架构： 使用 FreeRTOS 将电机驱动、逻辑计算、通信指令解耦为独立任务，实现了多任务并发与实时响应，利用消息队列与信号量管理任务间通信。

高鲁棒性循迹算法：

采用 重心法 (Weighted Average) 处理 8 路传感器数据，将离散的电平信号转化为连续的 -40~+40 线性误差。

设计 PD 控制器 (Kp=1.0, Kd=2.5)，配合独创的 “暴力死区穿越 (Violent Dead-zone Kick)” 逻辑，解决了低速下电机静摩擦导致的响应迟滞问题。

成果： 相比无算法的“砰砰控制(Bang-Bang Control)”，在相同跑道上过弯速度提升 40% 且无脱轨。

传感器融合与姿态解算：

基于 MPU6050 陀螺仪积分，实现了**“电子罗盘”功能。在避障模式下，利用陀螺仪反馈修正左右轮速差，实现了无参考线环境下的高精度直行**。

设计了带超时保护 (Software Fuse) 的传感器驱动，防止因硬件松动导致的系统死锁。

工程化容错设计：

通过软件层面的 PWM 通道映射重组 (Software Swap)，在不改动硬件电路的情况下完美解决了电机左右接线反接的问题。
